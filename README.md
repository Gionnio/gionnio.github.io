# gionnio.github.io

Personal site: [gionnio.github.io](https://gionnio.github.io). Plain HTML, CSS and JS, no build step.

- `content.json`: all texts, apps and sections, rendered by `main.js`.
- `style.css`: layout and graphics.
- `assets/icons`, `assets/shots`: app icons and screenshots.
- `patcher/`: [Tiny Little Patcher](https://github.com/Gionnio/tiny-little-patcher), a web app built in its own repository and copied here by its `deploy_site.sh`. Do not edit by hand.
